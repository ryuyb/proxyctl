The admin interface is not built

The agent is running and its API is available, but this binary was compiled without a front-end bundle.

Build it with pnpm --dir frontend/admin build, then rebuild this crate. A release build embeds whatever is in frontend/admin/dist/ at compile time.

Everything is reachable without this page: the API at /api/v1, and the commands proxyctl status, proxyctl tui.
